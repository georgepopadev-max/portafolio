# George Popa · Portfolio

Portfolio personal de George Popa, Full Stack Developer en Bizkaia (Java, Spring Boot y Angular) y fundador de Axonflow.

Es una web estática (HTML, CSS y JavaScript sin dependencias) desplegada en Vercel.

## Contenido

- **Sobre mí, experiencia y formación:** trayectoria en Ayesa Ibermatica para Iberdrola y proyecto propio Axonflow.
- **Proyectos:** [Axonflow](https://axonflow.es) y [Bilbao Reforma](https://www.bilbaoreforma.es), con qué son y cómo están hechos.
- **Contacto y CV:** `assets/cv-george-popa.pdf` es el CV en inglés.

## Estructura

```
index.html      página principal con todas las secciones
contacto.html   página de contacto
css/styles.css  estilos
js/main.js      menú, efecto de escritura y animaciones al hacer scroll
assets/         CV en PDF
icons/          iconos de tecnologías
```

Para verlo en local basta con abrir `index.html` o servir la carpeta con cualquier servidor estático.
