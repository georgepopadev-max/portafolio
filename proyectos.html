Energy Anomaly Detector

Dashboard para detección de anomalías en consumo energético utilizando modelos de Machine Learning. Implementa algoritmos de detección de patrones abnormales en tiempo real para identificar ineficiencias y posibles fraudes en instalaciones eléctricas.

Angular Spring Boot ML Python
Ver demo GitHub

Smart Grid Monitor

Sistema de monitorización en tiempo real de redes eléctricas inteligentes. Visualizaciones interactivas de flujos de energía, capacidades de generación renovable y predicciones de demanda mediante WebSockets para actualizaciones live.

Angular Spring Boot WebSockets D3.js
Ver demo GitHub

API Doc AI Generator

Generador automático de documentación para APIs REST utilizando inteligencia artificial. Analiza endpoints, esquemas de datos y respuestas para generar documentación interactiva clara y concisa, ahorrando horas de trabajo manual.

Angular Spring Boot OpenAI GPT-4
Ver demo GitHub

Code Health Checker

Herramienta de análisis estático para evaluar la calidad y complejidad de repositorios GitHub. Proporciona métricas de mantenibilidad, detección de code smells, análisis de deuda técnica e recomendaciones automáticas de mejora.

Angular Spring Boot GitHub API SonarQube
Ver demo GitHub

Incident Resolution Assistant

Asistente RAG (Retrieval Augmented Generation) para resolución de incidencias técnicas en el sector energético. Utiliza búsqueda vectorial para encontrar soluciones similares documentadas y genera recomendaciones basadas en el histórico de casos resueltos.

Angular Spring Boot Vector Search ChromaDB
Ver demo GitHub
